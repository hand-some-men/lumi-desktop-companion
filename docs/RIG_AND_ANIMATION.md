# LUMI — Rig and Animation Contract

Status: binding. The names and hierarchy below are enforced by
`src/lumi/character/rig_contract.py` and `tools/validate_glb.py`.

No rigged model exists yet. This is the contract an asset must satisfy; the
validator is the referee.

## 1. Armature

- Armature object name: **`Lumi_Rig`**
- Single armature, single skin, mixed hierarchy (no IK constraints required —
  baked clips are fine, constraints are optional).
- Nearest-bone or dual-quaternion skinning; the coat must not pinch at the
  shoulders or hips.
- Bone roll consistent along each limb so mirrored clips work.

## 2. Bones

Required (✱) bones must exist or validation fails. Optional bones improve
secondary motion and may be omitted.

| Bone | Parent | Req | Purpose |
| --- | --- | --- | --- |
| `Root` | — | ✱ | whole-character transform, origin between front hooves |
| `Hips` | Root | ✱ | centre of mass, carries the bob |
| `Spine` | Hips | ✱ | lower torso |
| `Chest` | Spine | ✱ | upper torso, breathing, squash |
| `Neck` | Chest | ✱ | head base |
| `Head` | Neck | ✱ | head, look-at target |
| `Jaw` | Head | | muzzle open for yawn/happy |
| `Horn` | Head | ✱ | spiral horn with cyan tip |
| `Ear_L` / `Ear_R` | Head | ✱ | ear flick |
| `Eye_L` / `Eye_R` | Head | ✱ | eye aim / parallax |
| `Eyelid_L` / `Eyelid_R` | Head | | blink if lids are separate geometry |
| `Wing_L` / `Wing_R` | Chest | ✱ | wing roots |
| `Wing_*_Feather1/2` | Wing_* | | layered feather segments |
| `Leg_FL` / `Leg_FR` | Hips | ✱ | front legs |
| `Leg_BL` / `Leg_BR` | Hips | ✱ | back legs |
| `Hoof_*` | Leg_* | | gold hoof caps, ground contact |
| `Tail1`…`Tail4` | chained | ✱ | tail root to curl |
| `Mane1` / `Mane2` / `Mane3` | Head/Neck/Chest | | mane strands |

Side suffixes are the **character's** left/right, not the viewer's. `FL` means
front-left leg, `BR` means back-right.

Counts: 21 required bones, 34 bones in the full contract.

## 3. Clips

All clips are authored in place (no root motion) and loop seamlessly where
marked. Clip names are `snake_case` and must match exactly.

| Clip | Loop | Req | Fallback | Notes |
| --- | --- | --- | --- | --- |
| `idle` | yes | ✱ | — | breathing, weight shift, tail sway |
| `blink` | no | ✱ | — | ~0.12 s single blink |
| `look_around` | yes | | idle | head turns left/right |
| `walk` | yes | ✱ | — | four-beat walk, no root motion |
| `run` | yes | ✱ | walk | faster gait, ears back |
| `turn_left` | yes | | walk | banked turn |
| `turn_right` | yes | | walk | banked turn |
| `fly_start` | no | | idle | crouch and push off |
| `fly` | yes | ✱ | — | wing flap loop, legs tucked |
| `fly_land` | no | | idle | flare and touch down |
| `sleep` | yes | ✱ | — | curled, slow breathing, eyes closed |
| `yawn` | no | ✱ | — | big stretch, open mouth |
| `happy` | no | ✱ | — | cheerful bounce |
| `surprised` | no | | idle | startle, wide eyes |
| `pet_reaction` | no | ✱ | — | leans into cursor, eyes closed |
| `play_ball` | yes | ✱ | — | crouch, pounce, chase |
| `sit` | yes | | idle | optional pose |

A missing required clip is an asset **error**. A missing optional clip silently
falls back and is reported as informational.

`dragged` is a *synthetic* clip: it is not in the asset table and is generated by
the renderer (dangling legs, flared wings). It is declared in
`animation.SYNTHETIC_CLIPS` so nothing tries to load it from the file.

## 4. Timing and blending

- 30 fps baked clips; sample rate 30 Hz is enough for this character.
- Cross-fade 0.15–0.25 s between locomotion clips, 0.10 s for reactions.
- `blink` is layered additively over any clip that does not already close eyes.
- Breathing and blink should be procedural on top of clips, so the same clips
  work at any speed.
- The state machine requests clauses by name; the animation layer resolves them
  against the file. It never invents motion for a clip that does not exist.

## 5. Behaviour → clip mapping

The behaviour machine (`src/lumi/character/state_machine.py`) emits
`ClipRequested` events. Its states map to clips as follows:

| State | Clip |
| --- | --- |
| `idle` | idle |
| `look_around` | look_around |
| `walk` | walk |
| `run` | run |
| `fly` | fly |
| `yawn` | yawn |
| `sleep` | sleep |
| `happy` | happy |
| `pet_reaction` | pet_reaction |
| `play_ball` | play_ball |
| `dragged` | dragged (synthetic) |

## 6. Validating a candidate asset

```bash
python tools/validate_glb.py path/to/lumi.glb --strict --json report.json
```

Errors (non-zero exit): missing required bone, missing required clip, no skin,
no geometry, bad container, missing POSITION.

Warnings (fail only with `--strict`): unknown bones/clips, hierarchy mismatch,
off-palette base colour, platform-like node names, implausible scale.

Run `pytest tests/test_rig_and_validation.py -q` after changing the contract.
